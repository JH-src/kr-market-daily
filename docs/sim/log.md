# 시뮬레이션 수정 이력

- r0_기준로직: 단계별 9개 버전(전체 유니버스 → 섹터 → 유형 → 관문 → 실적 → 개수 → 손절). 실적 조건만 뚜렷한 효과(설계 구간 3개월 +1.6%p, 6개월 +1.8%p). 개수 제한·순위와 20일 최저가 손절은 효과 없거나 해로움.
- 1회차 검토(버핏·드라켄밀러·최준철·버리·캐시 우드) 합의: ① 개수 제한 해제 ② 손절을 진입가 -15%로 완화 ③ 매출 기준 강화(20%)·가속 ④ 순위를 섹터 대비 강도로 ⑤ 초기 섹터의 주도주만. 버리: 월 단위 묶음 신뢰구간과 시험 횟수 기록 요구 → 반영.
- 추가 요청(엔진 보강 필요): 밸류(PER·PBR)·재무 건전성(부채비율), 종목별 수급, 추적 손절.

- r1_1회차수정: 시험한 설정 7개 — a 실적 통과 전부·손절 없음, b a + 매출 증가율 20% 이상, c a + 진입가 -15% 손절, d a + 초기 섹터의 주도주만, e a + 매출 증가율 가속, f 국면별 개수 유지 + 섹터 대비 강도 순, g 기존 최종(비교용)
