# 시뮬레이션 수정 이력

- r0_기준로직: 단계별 9개 버전(전체 유니버스 → 섹터 → 유형 → 관문 → 실적 → 개수 → 손절). 실적 조건만 뚜렷한 효과(설계 구간 3개월 +1.6%p, 6개월 +1.8%p). 개수 제한·순위와 20일 최저가 손절은 효과 없거나 해로움.
- 1회차 검토(버핏·드라켄밀러·최준철·버리·캐시 우드) 합의: ① 개수 제한 해제 ② 손절을 진입가 -15%로 완화 ③ 매출 기준 강화(20%)·가속 ④ 순위를 섹터 대비 강도로 ⑤ 초기 섹터의 주도주만. 버리: 월 단위 묶음 신뢰구간과 시험 횟수 기록 요구 → 반영.
- 추가 요청(엔진 보강 필요): 밸류(PER·PBR)·재무 건전성(부채비율), 종목별 수급, 추적 손절.

- r1_1회차수정: 시험한 설정 7개 — a 실적 통과 전부·손절 없음, b a + 매출 증가율 20% 이상, c a + 진입가 -15% 손절, d a + 초기 섹터의 주도주만, e a + 매출 증가율 가속, f 국면별 개수 유지 + 섹터 대비 강도 순, g 기존 최종(비교용)
- r1_1회차수정 결과: f(섹터 대비 강도 순·국면별 개수·손절 없음) 6개월 +5.8%p로 최고, 두 하위 구간 모두 플러스. 다만 7개 모두 95% 구간이 0 포함. 매출 20% 강화(b)·초기 주도주만(d)·손절(c)은 악화.
- 2회차 토론 합의: 다중 비교(누적 16개)를 늘리지 말고 f의 원인 분리에 집중 — 순위 효과(h), 손절 효과(i), 가속 결합(j) 3개만 시험. 밸류·수급은 자료 도착 후 f 위에 얹어 시험.

- r2_원인분리: 시험한 설정 3개 — h 기존 순위(매출 증가율)·손절 없음, i 섹터 대비 강도 순 + -15% 손절, j 섹터 대비 강도 순 + 매출 가속
- r2_원인분리 결과: 순위 효과 확인 — 매출 증가율 순(h) 6개월 +3.3%p vs 섹터 대비 강도 순(f) +5.8%p. -15% 손절(i)은 6개월 +4.2%p로 f보다 낮음(손절 비용 확인). 섹터 대비 강도 순 + 매출 가속(j) 6개월 +6.8%p, 95% 구간 +0.4~+14.6(처음으로 0 제외), 두 하위 구간 모두 플러스. 누적 시험 19개라 잠정. 독립 검증 진행.
- 독립 검증(r2 j): 미래 정보 사용 없음, 표본 10건 가격·실적·공시 모두 원자료와 일치. 그러나 ① 상위 5건 제외 시 6개월 +6.8%p → +0.9%p, 중앙값 -2.9% ② 6개월 보유 기간 겹침 반영 시 95% 구간 -0.1~+15.1(0 포함) ③ 다중 비교 반영 99.7% 구간 -3.2~+20.6 ④ 가격 처리 오류: 주가 변동 없이 주식수만 15% 넘게 는 날을 분할로 오인해 가짜 수익 발생(2016.6~2024.6 794건, 시장 평균·섹터 지수에 영향), 무상증자 권리락일 처리, 흡수합병 소멸 종목 처리. → j 채택 보류.
- 조치: 분할 판정에 '가격이 반대로 실제 움직였을 것' 조건 추가, 결과표에 기간 겹침 반영 구간·상위 5건 제외·종목 중앙값 추가. r3는 같은 설정(a·f·h·j)을 보정 자료로 다시 계산(새 가설 아님).

- r3_가격보정후: 시험한 설정 4개 — a 실적 통과 전부·손절 없음, f 섹터 대비 강도 순, h 매출 증가율 순, j 섹터 대비 강도 순 + 매출 가속
- 자동 탐색 1회차(로컬, 24,195개 로직, 밸류·수급 미포함): 걷기식 검증 평균 3개월 +3.19%p, 6개월 +5.05%p, 6개월 이긴 비율 45.2%(2019~2023 각 해 이전 자료로 고른 로직을 그해 적용). 해마다 뽑힌 로직이 공통으로 '주도 섹터의 차기주자 + 실적 상승세·매출 가속 + 섹터 대비 1개월 덜 빠진 순' 쪽으로 모임(2021~2023은 세부 섹터 분류). 2020년 3개월은 마이너스. 이후 GitHub 자동 탐색(6시간 주기)으로 이관.
