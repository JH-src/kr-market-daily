# 일별 시장 동향·종목 선별 체계 — 최종 모델 v3 (2026-10-16)
# 사전 등록 문서 초안. 모든 수치는 출발값이며, 검증 전 임의 조정 금지. 변경 시 이유 기재·재등록·구 규칙 1년 그림자 운용.

## 0. 체계의 정체
"주도 섹터 안에서, 싼 이유가 구조적이지 않고, 변화가 다음 순서로 도달 중이며, 아직 가격에 반영되지 않은 종목을 단계적으로 잡는다."
가치는 '무엇을 살 수 있는가'의 관문, 가격·유동성은 '언제 얼마나'의 방아쇠와 상한. 가치 점수는 타이밍 변수가 아니다.

## 1. 데이터 기초 (백테스트 전 관문)
- 섹터 분류: 표준산업분류 기본층(시점 기준 백테스트 가능) + 테마 수작업층(오늘부터 앞으로만 평가, 백테스트 금지) + 세부 사이클. 종목 편입 시작일 버전 관리.
- 상장폐지 종목 포함 검증, 수정주가 계수(상장주식수 변화 + DART 액면분할·무상증자·배당), 재무는 제출일 기준·정정 전 원본.
- 지수: 강도 판정은 거래대금 가중·상한 지수, 동일가중은 확산도 계산 전용. 벤치마크는 실제 투자 가능한 섹터 ETF 또는 유동성 상위 구성.
- 제외 목록: 지주사·중복상장 모회사(상장 자회사 지분가치÷시총 기준), 우선주, 금융, SPAC, 관리종목, 거래정지.

## 2. 1층 시장 국면 + 유동성 관문 (총노출 상한과 신규·추가 허용만 결정)
- 가격 3개: KOSPI 대 200일선, 확산도(60일선 상회 비율·신고가−신저가), 레버리지·인버스 ETF 좌수 변화.
- 유동성 점수(주 단위): 한국은행 기준금리 사이클, 국고채 3년 수익률 추세, 통화량. 원화·달러·선물 베이시스·내재변동성·풋콜은 화면 표시만.
- 규칙: 점수만 긴축이면 신규·추가 제한. 긴축 4주 지속 + KOSPI 200일선 아래 → 총노출 상한 60%로, 초과분만 축소(순서: 돌파 추가분 → 확인 약한 후발주 → 유동성 낮은 것). 가치 진입분은 종목·섹터 규칙으로만 매도. 변경은 주 1회.

## 3. 2층 섹터 단계 (변화 축 + 가격 축, 비대칭 판정)
- 변화 축: 품목별 수출 증가율 변곡(관세청), 섹터 합산 잠정실적 가속, 대형 고객사 신규시설투자 공시 + 사업보고서 설비투자 계획, 장비사 공급계약 12개월 누적액÷매출 변곡, 소재사 가동률 추이.
- 가격 축: 거래대금 가중 섹터 지수의 KOSPI 대비 상대강도(3·6개월), 섹터 내 확산도, 선두주 신고가 여부.
- 과열·중단 전용(단독 유효): 섹터 거래대금 비중 ≥ 1년 중앙값×2, 60일선 상회 비율 80%대, 레버리지 섹터 ETF 좌수 급증, 후발주 일제 상승(섹터 내 수익률 분산 축소·약한 종목이 선두 추월).
- 단계: 초기 = 변화 축 켜짐 + 상대강도 양전환(확산도 낮음) / 주도 = 변화·가격 둘 다 지속 + 선두주 신고가(최소 지속 2주) / 과열 = 가격 극단 + 변화 가속 둔화 / 쇠퇴 = 선두주 60일선 이탈·3개월 상대강도 음전환(실물 무관, 지속 기간 조건 없음).
- 초기→주도 승격은 변화 축이 켜져 있을 때만. ETF 좌수·거래대금 비중은 단독으로 단계를 바꾸지 못함.
- 세부 사이클 선후행은 통계 추정 없이 손으로 적은 공급망 지도를 가설로 운용. 매주 '미분류 군집'(52주 신고가 + 거래대금 급증인데 기존 꼬리표 없음) 추출 후 수작업 명명.

## 4. 3층 종목 (진입 구간 = 초기·주도 섹터)
### 필수 관문 (하나라도 걸리면 탈락, 점수 합산 금지)
- 이익의 질: 3년 누적 영업현금흐름÷영업이익 < 0.5
- 운전자본: 매출채권·재고 회전일이 3년 평균 대비 30% 이상 증가하며 매출 증가율을 2년 연속 상회(장비사는 수주잔고 동행 시 예외)
- 희석: 미전환 CB·BW·전환우선주 전환가능주식수÷유통주식수 > 10%면 완전희석 기준 재계산(리픽싱은 최저 조정가), 2년 내 리픽싱 감점; 3년 내 증자·CB·BW 2회 이상 + 누적 잉여현금흐름 음수 → 탈락
- 관계사: 특수관계자 매출·매입 30% 초과 또는 대여·보증÷자기자본 10% 초과
- 최대주주 담보 ÷ 보유 주식 50% 초과; 승계 구간 징후(수증·2세 선임·개인회사 거래 겹침)는 감점
- 우발채무(소송·보증÷자기자본 20% 초과) 감점, 개발비 자산화 증가분이 영업이익 절반 이상이면 차감 재계산
- 감사: 비적정·계속기업·내부회계 비적정·잦은 감사인 교체; 불성실공시·경영권 분쟁·계열사 합병 이력
- 자사주는 소각만 환원으로 인정(취득 후 처분 이력 감점)
### '왜 안 올랐는가' 필수 기재 — (가)만 후보
- (가) 군중이 아직 안 본 것: 산업분류가 테마와 다름, 테마 ETF 비구성(구성종목 수집 불가 시 커버리지·회전율로 대체), 회전율 낮음
- (나) 군중이 보고 버린 것: 관문 적신호 보유. 테마 ETF 구성종목이면서 섹터 출발 후 섹터 지수에 뒤처진 종목은 (나)로 간주, 제외
### '변화 도달 단계' 꼬리표 — '도달 중'만 매수
- 이미 반영(선두) / 도달 중(수주잔고·가동률·잠정실적·공급계약이 방향을 바꾸기 시작) / 미도달(관찰 목록)
### 순위 (후보 간)
- 5년 현금 환원 이력(소각 누계÷시총, 배당 증가·삭감 횟수, 배당÷영업현금흐름, 제고계획 실행 여부) → 절대 밸류(자기 5년 밴드 위치, 소유주 이익 근사÷시총, 순현금÷시총, EV/영업현금흐름 섹터 하위 25%) → 테마 매출 비중(부문별 매출, 주요 매출처·공급계약 상대방으로 교차)
- 선두주 대비 밸류에이션 격차는 순위·타이밍 변수에서 제외. 후보 관문(격차 ≥ 섹터 중앙값)과 매도 목표로만 사용.
- 포지션 상한: 최근 60일 하락일 평균 거래대금 기준 5거래일 내 전량 청산 가능 규모.

## 5. 진입 트랜치
- 1차(가치 진입, 목표 비중의 1/3; 초기 단계 섹터면 1/4): 관문 통과 + (가) + 도달 중 + 섹터 대비 4주 상대강도가 신저점이 아닐 때, 돌파 전 실행 가능. 진입 전 저점을 일지에 기재.
- 2·3차(본 비중): 20일 신고가 돌파 + 거래대금 ≥ 60일 중앙값×2 + 4주 섹터 대비 상대강도 양전환 발생일에만. 물타기 금지, 추가는 오르는 종목에만.
- 과열 단계에서는 어떤 트랜치도 신규·추가 금지.

## 6. 매도 규칙 (진입 시 전부 일지에 기재, 없으면 진입 금지; 규칙 매도는 일 단위 자동)
1. 논지 훼손 공시 당일 전량: 유상증자·CB·BW 결정, 리픽싱, 최대주주 담보 추가·반대매매, 감사 문제, 관계사 거래 급증, 임원 군집 매도, 공급계약 해지·정정, 잠정실적 마진 하락. 분기 내 재진입 금지.
2. 가치 실현: 선두주가 60일선 위인 상태에서 진입 시 격차의 절반이 닫히면 절반 매도, 선두주 배수의 80%에 닿으면 전량. 선두주 하락으로 닫힌 격차는 섹터 손절 사안.
3. 시간 손절: 2·3차분은 6주, 1차분은 13주 내 섹터 대비 상대강도 양 유지 실패 시 청산.
4. 가격 손절: 2·3차분은 돌파 전 저점 이탈, 1차분은 진입 전 저점 이탈. 공통 섹터 대비 -15%.
5. 섹터 손절: 선두주 60일선 이탈 → 해당 섹터 후발주 절반 축소, 3개월 상대강도 음전환 확인 → 전량. 과열 진입 → 위성(후발주)부터 축소, 쇠퇴까지 보유 금지.
6. 유동성: 20일 평균 거래대금이 진입 시 절반 이하 → 축소 시작.

## 7. 포트폴리오 구조
- 섹터 예산의 1/3~1/2은 핵심(섹터 ETF 또는 선두주; 확인된 후발주가 없을 때 ETF로 채우고 가격 확인된 후발주 순으로 교체), 나머지는 위성(후발주 최대 3~4종목). 비중은 변화 증거·가격 확인·유동성 환경 세 축이 맞을 때만 최대.

## 8. 운영 주기
- 매일: 수집·갱신·예측 일지(판단 시점 변수 스냅샷). 화면은 공시(실적·수주·증자·내부자)가 가격보다 먼저, 일별 손익 미표시. 규칙 매도 자동.
- 매주: 섹터 단계 재판정, 미분류 군집, 돌파 추가 점검, 후보 등록, 지난주 채점.
- 매월(또는 실물 공시 발생 시): 1차 가치 진입·재량 교체. 재무·분류 점검.
- 분기: 규칙 재검토는 그림자 운용 조건 하에서만.
- 조사와 매매 분리: 섹터 쇠퇴·바닥 때 DART 원자료로 대기 명단 작성, 2층이 확인할 때 실행.

## 9. 검증·자기기만 방지
- 사전 등록: 가설당 주 사양 1개(나머지는 민감도만, 선택 금지), 가중치, 중단 기준. 기간 전·후반과 유가·코스닥 모두에서 유지될 때만 채택.
- 비교 대상: 같은 기간 해당 섹터(투자 가능한 ETF 또는 유동성 상위 지수). 종목 층이 못 이기면 폐기.
- 분리 채점: 1차분/2·3차분, 탈락 후보, 선두주, 사람 재량 결정, 구 규칙 — 모두 그림자 채점.
- 1차 지표: 고정 기간(4·13·26주) 섹터 대비 수익률. 목표 도달률(+15/+30%)은 보조이며 미도달·사전 최대 낙폭과 함께.
- 체결: 금요일 신호 → 월요일 종가 또는 가중평균가, 충격비용은 주문÷거래대금 함수, 거래세·수수료 포함.
- 성과 지표에 회전율·매매 횟수·비용 합계·6~12개월 보유 수익 포함.
- 연 단위 굴리는 순차 검증, 결과 산포 보고. 2010년 이후 독립 사이클 대여섯 개 → 일화 수준임을 명시. 공매도 금지 구간·밸류업 이후는 별도 체제로 표기.

## 10. 명시된 한계
- 투자자별 매매·공매도·신용잔고는 거래소 API에 없음 → 한국투자증권 Open API(조회 전용)로 보완(2026-10-16). 종목별 투자자 매매는 2020년, 시장 전체는 2015년까지 조회 확인.
- 수주잔고는 기재 회사만, 잠정실적은 대형주 위주. 해외 요인·디램 가격은 직접 확보 불가. ETF 구성종목은 한투 조회로 ETF당 비중 상위 30종목까지만 확보(과거 이력 없음, 2026-10-16부터 매일 누적).
- 적중률은 반반 근처가 정상. 수익은 비대칭(작은 손실·큰 이익)과 과열 회피에서 나온다.
- 실제 매매 전 증권사 임직원 매매 규정 확인 필요.

## 11. 변경 이력
### v3.1 (2026-10-16) — 추세·수급 근거 추가, 그림자 운용으로 등록
변경 이유: 시장의 상위 선택(운용역이 담는 종목)과 수급·과열 정도도 진입 근거가 된다는 판단. 섹터 단계만으로는 같은 섹터 안 종목 간 차이를 설명하지 못하고, 운용사가 매일 공개하는 편입 내역은 '누가 이미 사고 있는가'를 직접 보여 준다.
